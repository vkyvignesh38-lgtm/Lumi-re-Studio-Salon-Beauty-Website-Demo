# Lumière Studio — Beauty, Grooming & Wellness (Demo)

> **Demo Project.** Lumière Studio is a fictional brand created for portfolio demonstration purposes. It is not a real salon. It shows no real clients, reviews, awards, certifications, staff or business results.

## Project Overview

Lumière Studio is a multi-page website for a fictional **unisex** beauty, grooming and wellness studio in Chennai. It is Demo #2 in a freelance web design portfolio. The site welcomes women and men equally. It uses a premium editorial look: warm ivory, champagne and deep wine, with charcoal and muted gold.

- **Tagline:** “Beauty, Grooming & Wellness — Designed Around You.”
- **Hero:** “Look Good. Feel Confident.”
- **Stack:** static HTML, CSS and vanilla JavaScript, generated by a small Python build script. There are no frameworks and no runtime dependencies.

## Features

- **Pages built from data:** services, pricing, team, gallery and photo credits come from JSON files.
- **Shared components:** the header, footer, cards and CTA band are written once and reused on every page.
- **Sticky header with an accessible mobile menu:** it sets `aria-expanded` and `aria-controls`, and keeps focus inside the menu while it is open. Esc closes it and returns focus to the toggle. Choosing a link or clicking outside also closes it.
- **Service filtering** works by category (All, Hair, Skin, Grooming, Bridal, Makeup, Spa, Nails) and by customer type (Everyone, Women, Men, Unisex):
  - The URL keeps the current filters, e.g. `services.html?audience=men&category=hair`.
  - A live result count updates as filters change, and an empty state appears when nothing matches.
- **Pricing tabs** (Women, Men, Unisex, Bridal) follow the WAI-ARIA tabs pattern:
  - Arrow keys, Home and End move between tabs.
  - Links such as `pricing.html#bridal` open a specific tab.
- **Masonry gallery** with filters (All, Hair, Grooming, Makeup, Bridal, Spa, Studio). Its accessible lightbox supports:
  - opening, closing, previous and next
  - the keys ← → Home End Esc
  - touch swipe
  - browsing only the photos in the current filter
  - returning focus to the thumbnail on close
- **Appointment form:**
  - The service list changes with the customer type. Women and Men also see unisex services.
  - Every "Book Now" button pre-selects its service (`appointment.html?service=beard-styling`).
  - Time slots follow studio hours. Sunday closes at 6 PM, and same-day slots need one hour's notice.
  - Each field shows its own error message (name, phone, email, customer type, service, date and time). An error summary links to each problem.
  - A successful request shows **“Appointment request received.”** followed by **“Demo booking only — no real appointment has been scheduled.”**
  - **Book via WhatsApp** opens `wa.me` with a pre-filled message containing Name, Customer Type, Service, Date and Time. **Send via Email** opens a pre-filled `mailto:` message.
- **“Open Today” card** shows today's hours, calculated in studio time (Asia/Kolkata). The Contact page highlights today's row in the hours list.
- **Accessibility:**
  - semantic landmarks, a skip link, labelled form controls and visible focus states
  - colour contrast that meets WCAG AA
  - `prefers-reduced-motion` support, which turns off reveal and hover motion
- **SEO:**
  - a unique title and meta description on every page
  - Open Graph and Twitter tags
  - SVG and PNG favicons plus an Apple touch icon
  - `width` and `height` on every image to prevent layout shift
  - lazy-loading for images below the fold
  - canonical tags ready to switch on (see Build Instructions)
- **Responsive layout,** tested at every width from 320px to 2560px in portrait and landscape.

## Tech Stack

- **HTML5,** generated by `_src/build.py` (Python 3.8+, standard library only)
- **CSS3** in one stylesheet, using custom properties, Grid, Flexbox, `clamp()` and CSS columns for the masonry
- **Vanilla JavaScript (ES5-compatible).** Each module is a small IIFE that registers on `window.Lumiere.modules`, and `main.js` starts them. There are no inline handlers and no globals beyond the `Lumiere` namespace.
- **Google Fonts:** Cormorant Garamond for headings and Manrope for body text
- **Photography** from Unsplash (see Photo Credits)

## Local Setup

The generated HTML files are already included, so you can open `index.html` directly in a browser.

For behaviour closer to a real host, serve the folder locally:

```bash
cd lumiere-studio
python -m http.server 8000
# open http://localhost:8000
```

## Build Instructions

Edit the files in `_src/`, then regenerate the pages:

```bash
python _src/build.py                 # rebuild all 9 pages
python _src/build.py --fetch-images  # re-download any missing photo listed in images.json, then build
```

- **Add or change a service:** edit `_src/data/services.json`. The service grid, the "Book Now" links and the appointment form's options all update on rebuild. Add the photo to `images.json` first.
- **Change prices:** edit `_src/data/pricing.json`.
- **Turn on canonical and `og:url` tags:** set `"baseUrl"` in `_src/data/site.json`, e.g. `"https://example.com/lumiere-studio"`, then rebuild.
- Template syntax: `{{> component }}` includes a component file and `{{ key }}` inserts a value. The build stops with an error if a variable is undefined or an image file is missing.

## Future Backend Plan

To turn the demo into a real studio website:

1. **Booking API:** replace the client-only submit handler in `assets/js/modules/appointment.js` with a `POST /api/appointments` call. Candidates are a serverless function (Netlify or Vercel), or Node/Express or Django with PostgreSQL. Validate on the server with the same rules used in the browser.
2. **Availability:** store specialists, services and time slots in the database, and return free slots from `GET /api/availability?date=&service=` instead of building them in JavaScript.
3. **Notifications:** confirm requests by email (Resend or SES) and by WhatsApp through the WhatsApp Business Cloud API, using a real studio number.
4. **CMS:** move `services.json`, `pricing.json`, `team.json` and `gallery.json` into a headless CMS such as Sanity, Strapi or Decap. Run `build.py`, or a static generator, from a webhook.
5. **Admin dashboard:** let staff view, confirm and reschedule appointments, with role-based access.
6. **Compliance:** add a privacy policy, consent for contact by phone or WhatsApp, spam protection (honeypot or Turnstile), rate limiting and secure storage of personal data.
7. **Analytics and SEO:** add privacy-friendly analytics, a `sitemap.xml`, `robots.txt` and `LocalBusiness` structured data. Add structured data only once the business and its details are real.
